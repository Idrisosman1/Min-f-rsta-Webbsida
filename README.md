# Min första webbsida

## Vad har jag lärt mig?

Under den här veckan har jag fått lära mig lite om HTML, Git och GitHub. I början var det ganska mycket nytt, särskilt alla kommandon i terminalen. Men när jag började testa själv blev det lättare att förstå hur allt hänger ihop.

## Vad är HTML?

HTML används för att skapa innehållet på en webbsida. Man kan till exempel lägga till rubriker och vanlig text.

Här är ett enkelt exempel:

```html
<h1>Hej världen!</h1>
<p>Det här är min första webbsida.</p>
```

`h1` betyder en huvudrubrik och `p` används för ett textstycke. När man öppnar HTML-filen i webbläsaren visas rubriken och texten.

## Vad är Git och GitHub?
Git och GitHub används ofta tillsammans när man arbetar med kod, men de är inte samma sak.

Git är ett verktyg som hjälper oss att hålla reda på ändringar i ett projekt. Om jag till exempel ändrar något i min HTML-kod kan jag använda Git för att spara en ny version. På så sätt kan jag se vad jag har ändrat och gå tillbaka till en tidigare version om något skulle bli fel.

GitHub är en webbplats där jag kan lägga upp mina projekt på internet. Där kan andra se min kod och jag kan även samarbeta med andra personer. GitHub gör det också möjligt att komma åt projektet från olika datorer.

Skillnaden mellan Git och GitHub är alltså att Git används för att spara och hantera ändringar, medan GitHub används för att lagra och dela projekten online.

### Ett exempel från min egen övning

När jag skapade min första webbsida använde jag Git för att spara mina ändringar med git add och git commit. När jag sedan ville lägga upp projektet på GitHub använde jag git push.

Det hjälpte mig att förstå att Git och GitHub har olika uppgifter, men att de fungerar bra tillsammans.

## Några kommandon jag har lärt mig

- `git status` – visar om något har ändrats.
- `git add` – väljer vilka ändringar som ska sparas.
- `git commit` – sparar en version av ändringarna.
- `git push` – laddar upp sparade ändringar till GitHub.

## Mitt tips till andra nybörjare

Mitt tips är att testa sig fram och inte vara rädd för att inte göra fel. Jag märkte själv att det blev mycket lättare när jag började skriva kommandona och se vad som faktiskt hände. Det viktigaste är att ta ett steg i taget.
