# Min första webbsida

## Vad har jag lärt mig?

Under den här veckan har jag fått lära mig lite om HTML, Git och GitHub. I början var det ganska mycket nytt, särskilt alla kommandon i terminalen. Men när jag började testa själv blev det lättare att förstå hur allt hänger ihop.

## Vad är HTML?

HTML används för att skapa innehållet på en webbsida. Man kan till exempel lägga till rubriker och vanlig text.

Här är ett enkelt exempel:

```html
<h1>Hej världen!</h1>
<p>Det här är min första webbsida.</p>
```

`h1` betyder en huvudrubrik och `p` används för ett textstycke. När man öppnar HTML-filen i webbläsaren visas rubriken och texten.

## Vad är Git och GitHub?

Git hjälper oss att hålla reda på ändringar i ett projekt. Om man ändrar något i sin kod kan man spara en version och gå tillbaka och se vad man gjort tidigare.

GitHub är en webbplats där man kan lägga upp sitt projekt så att andra också kan se det.

## Några kommandon jag har lärt mig

- `git status` – visar om något har ändrats.
- `git add` – väljer vilka ändringar som ska sparas.
- `git commit` – sparar en version av ändringarna.
- `git push` – laddar upp sparade ändringar till GitHub.

## Mitt tips till andra nybörjare

Mitt tips är att testa sig fram och inte vara rädd för att göra fel. Jag märkte själv att det blev lättare när jag började skriva kommandona och se vad som faktiskt hände. Det viktigaste är att ta ett steg i taget.
